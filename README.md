# 🏥 Hospital Data Analytics Dashboard

An interactive and insightful **Hospital Data Analytics Dashboard** developed using **Power BI** and **SQL** to analyze hospital operations, patient records, doctor performance, appointments, medicine tracking, and financial data.

This project transforms raw healthcare data into meaningful insights through interactive dashboards and visualizations to support better decision-making in hospital management.

---

# 📌 Project Overview

The main objective of this project is to analyze and visualize healthcare data in a simple and interactive way using Business Intelligence tools.

The dashboard helps users understand:

* Hospital performance
* Patient details and treatment analysis
* Doctor performance and appointments
* Medicine stock and sales
* Financial reports and revenue trends
* Bed occupancy and surgery information

SQL was used to extract, filter, clean, and manage the hospital dataset before importing the data into Power BI for visualization and dashboard development.

# 🔄 Project Workflow

1. Collected hospital datasets from Excel/CSV files
2. Used SQL queries for:

   * Data extraction
   * Data filtering
   * Data cleaning
   * Data management
3. Imported processed data into Power BI
4. Created relationships and data models
5. Developed interactive dashboards using DAX, KPIs, charts, and slicers
6. Generated meaningful healthcare and financial insights
